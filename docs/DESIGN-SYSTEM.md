# سیستم طراحی هویدا

جهت هنری: **«وضوح سازمانی»** — ارزش‌ها: وضوح، هوشمندی، اعتماد.
پیاده‌سازی: توکن‌ها در `src/index.css` (Tailwind v4 `@theme`)، اجزا در `src/components/ui`، برند در `src/components/brand`.

## ۱. برند

| دارایی | فایل |
| --- | --- |
| نشان رنگی (گرادیان + ستاره سفید با سایه نرم) | `public/brand/hovida-mark.svg` / `<HovidaMark />` |
| نشان تخت (فقط روی پس‌زمینه‌های روشن) | `hovida-mark-flat.svg` / `variant="flat"` |
| نشان تک‌رنگ سفید / زغالی | `hovida-mark-white.svg`، `hovida-mark-charcoal.svg` |
| آیکن اپ و فاوآیکن (کاشی سبز ملایم) | `hovida-app-icon.svg`، `public/favicon.svg` / `variant="tile"` |
| لوگوتایپ (هویدا + HOVIDA) و ترکیب افقی | `hovida-wordmark.svg`، `hovida-lockup.svg` / `<HovidaLogo />` |

نشان از دو قطعه درهم‌تنیده و یک **ستاره چهارپر «روشنی»** در محل اتصالشان ساخته شده است. لوگوتایپ از Vazirmatn (وزن ۹۰۰) و Inter به منحنی تبدیل شده و به فونت نصب‌شده وابسته نیست. بازتولید: `npm run brand`.

**شعار:** آنچه مهم است، روشن می‌شود. · **زیرشعار:** تحلیل هوشمند رزومه‌ها برای تصمیم‌های بهتر در منابع انسانی · **پانویس:** هویدا • تحلیل دقیق‌تر، تصمیم بهتر

## ۳. تایپوگرافی

- **Vazirmatn** برای رابط فارسی؛ **Inter** فقط برای حروف لاتین، ارقام لاتین و @ (با `unicode-range`)، پس نام‌های انگلیسی، ایمیل‌ها و اصطلاحات فنی خودکار با Inter نمایش داده می‌شوند.
- اندازه‌ها: ۱۱٫۵ (برچسب) · ۱۲٫۵–۱۳٫۵ (متن) · ۱۴–۱۵ (عنوان کارت) · ۲۲–۲۴ (عنوان صفحه) · ۳۴–۵۲ (لندینگ).
- ارقام در رابط فارسی‌اند (`toPersianDigits`، `faNumber`)؛ تاریخ‌ها شمسی و بر اساس ساعت تهران.
- متن‌های چندجهته با `dir="auto"` / `<bdi>`؛ عددهای کنار هم در جدول‌ها به‌صورت اجزای جدا (flex) تا الگوریتم bidi آن‌ها را به هم نچسباند.

## ۵. چیدمان

- **دسکتاپ:** نوار کناری راست ۲۵۶px (لوگو، منو، وضعیت هوش مصنوعی، کارت کاربر)، نوار بالا (جست‌وجو، اعلان‌ها، «ایجاد فرصت شغلی»).
- **صفحه فرصت شغلی:** کارت‌های آمار ← فیلترها ← جدول (چک‌باکس، کاندید، وضعیت، درصد، مهارت‌ها، تصمیم) ← پنل جزئیات در ستون چپ با زبانه‌های خلاصه / مهارت‌ها / تجربه / اطلاعات بیشتر.
- **موبایل:** کارت‌های کاندید با درصد، کشوی تمام‌صفحه برای جزئیات، ناوبری پایین (خانه، فرصت‌ها، رزومه‌ها، مقایسه، بیشتر).
- شعاع: کارت ۱۴px، کنترل ۱۰px، برچسب‌ها کامل. سایه حداقلی؛ مرزها کار را انجام می‌دهند. بدون گرادیان سنگین و کارت تودرتو.

## ۶. لحن و محتوا

- حرفه‌ای و گرم، با خطاب «شما».
- هوش مصنوعی هرگز «استخدام کنید / رد کنید» نمی‌گوید؛ فقط میزان تطابق را توصیف می‌کند.
- پرهیز از تصاویر مغز، چشم، ذره‌بین یا مدار به‌عنوان استعاره هوش مصنوعی.
- هیچ عدد بازاریابی ساختگی؛ برآوردها برچسب «برآورد» و فرض محاسبه دارند.
