# برابری فرصت‌ها

سؤال ساده است: **آیا در هر مرحله، گروهی را بیشتر کنار می‌گذاریم؟** پاسخش فقط وقتی معنا دارد
که سه قاعده رعایت شود — داوطلبانه بودن، پنهان ماندن از تصمیم‌گیرنده، و پنهان‌سازی گروه‌های کوچک.
هویدا هر سه را در خود محصول اجرا می‌کند، نه در یک سند سیاست.

## روشن و خاموش کردن

تنظیمات › سازمان › **برابری فرصت‌ها** (فقط مدیر):

| گزینه | پیش‌فرض | معنا |
| --- | --- | --- |
| جمع‌آوری اطلاعات داوطلبانه | خاموش | تا روشن نشود، هیچ پاسخی از هیچ کارجویی ذخیره نمی‌شود |
| حداقل اندازهٔ گروه در گزارش | ۵ | گروه کوچک‌تر از این عدد در گزارش پنهان می‌شود (۲ تا ۵۰) |

خاموش‌کردن، جمع‌آوری **پاسخ‌های تازه** را متوقف می‌کند؛ داده‌های پیش‌تر ذخیره‌شده دست‌نخورده
می‌مانند و گزارش همچنان قابل خواندن است (با همان یادداشت «خاموش است»).

## فرم کارجو

در پورتال شغلی، بخش تاشوی «برابری فرصت‌ها (داوطلبانه و بی‌نام)» با سه پرسش: جنسیت، گروه سنی،
معلولیت یا بیماری مزمن. برای هر سه گزینهٔ **«ترجیح می‌دهم نگویم»** هست و پاسخ‌دادن به هیچ‌کدام
الزامی نیست. متن بالای فرم صریح است: پاسخ‌ها کنار نام دیده نمی‌شوند و در تصمیم اثری ندارند.

- اگر کارجو هیچ‌کدام را پر نکند، چیزی ذخیره نمی‌شود (نه «نامشخص»، نه حدس).
- مقدار ناشناخته به «ترجیح می‌دهم نگویم» تبدیل می‌شود، نه به یک دستهٔ ساختگی.
- سن به‌صورت **گروه سنی** ذخیره می‌شود، نه تاریخ تولد.

## پنهان‌ماندن از تصمیم

پاسخ در هیچ پیلود کارجویی برنمی‌گردد:

- فهرست کاندیداها، پنل کارجو، خروجی‌ها و مقایسه
- «غربالگری بی‌طرف» و لحظهٔ آشکارسازی هویت
- پیشنهاد شغلی، کیت مصاحبه و پیام‌ها
- موتور غربالگری هم این فیلد را نمی‌خواند

تنها جایی که داده دیده می‌شود، گزارش تجمیعی مدیر است.

## گزارش

گزارش‌ها › **برابری فرصت‌ها** (فقط مدیر و مالک؛ عضو پاسخ `403` می‌گیرد):

- **درخواست و استخدام** به تفکیک جنسیت، گروه سنی و معلولیت.
- **نرخ پاسخ داوطلبانه** — چند نفر از کل درخواست‌ها پاسخ داده‌اند.
- **خانه‌های کوچک‌تر از حد** با نشان «کمتر از ۵ نفر» نمایش داده می‌شوند؛ نه تعداد و نه درصد.
- **به تفکیک فرصت شغلی** برای دیدن اینکه یک نقش خاص گروه خاصی را جذب می‌کند.
- جملهٔ صادقانهٔ بالای صفحه: با دادهٔ کم، گزارش می‌گوید «داده کافی نیست»؛ صفر یعنی «داده نداریم»،
  نه «تفاوتی نیست».
- بخش «این گزارش چه چیزی را نشان نمی‌دهد»: همبستگی ≠ علت، و هیچ تصمیمی از این داده گرفته نمی‌شود.

## API

| مسیر | کار |
| --- | --- |
| `GET /api/reports/eeo?range=30\|90\|365\|all` | گزارش تجمیعی (فقط مدیر) |
| `PATCH /api/org` با `eeo: { enabled, threshold }` | روشن/خاموش و حد پنهان‌سازی (فقط مدیر) |
| `GET /api/careers/:slug` | `portal.eeoEnabled` — آیا فرم داوطلبانه نشان داده شود |
| `POST /api/careers/:slug/jobs/:id/apply` | `eeo?: { gender, ageBand, disability }` |

## آزمون

```bash
npm run test:eeo
```

۳۶ بررسی: خاموش‌بودن پیش‌فرض و ذخیره‌نشدن پاسخ، فقط-مدیر بودن تنظیم و گزارش، حداقل حد،
ذخیرهٔ پاسخ‌ها، «ترجیح می‌دهم نگویم» به‌عنوان یک پاسخ، پنهان‌سازی خانه‌های کوچک، نبودِ فیلد در
فهرست/پنل/حالت بی‌طرف/آشکارسازی، نمایش گروه بالای حد با درصد واقعی و توقف جمع‌آوری بعد از خاموشی.
