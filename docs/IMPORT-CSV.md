# وارد کردن فهرست پروفایل از فایل (CSV) — بدون هیچ کلید

مسیر سوم جست‌وجوی استعداد: اگر دسترسی API ندارید ولی **صندلی LinkedIn Recruiter** (یا هر منبع دیگری) دارید،
همان فهرستی که در پنل لینکدین پیدا کرده‌اید را به هویدا بیاورید. این کار:

- **هیچ کلیدی لازم ندارد** و هیچ درخواستی به بیرون نمی‌فرستد؛ فایل فقط روی سرور خودتان خوانده می‌شود؛
- همان مسیر پروفایل‌های API را می‌رود: همان **موتور غربالگری**، همان **تشخیص تکراری**، همان **منبع/ردیابی**؛
- برای سازمان‌هایی که نمی‌خواهند داده را از سرویس ثالث بگیرند، کم‌ریسک‌ترین مسیر است (شما خودتان داده را
  با مجوز Recruiter دیده‌اید و صادر کرده‌اید).

## چطور استفاده می‌کنم؟

۱. در LinkedIn Recruiter جست‌وجو را انجام دهید و نتیجه را **Export** کنید (CSV).
۲. در هویدا: **«جست‌وجوی استعداد»** (`/app/sourcing`) → کارت **«فهرستی از قبل دارید؟ (CSV)»**.
۳. فایل را انتخاب کنید یا متن جدول را بچسبانید (`Ctrl+A` روی جدول → کپی).
۴. **«بررسی فایل»**: هویدا می‌گوید کدام ستون‌ها شناخته شده‌اند، چند ردیف خوانده شد و چه چیزی کنار گذاشته می‌شود.
۵. دپارتمان (و در صورت نیاز فرصت شغلی) را انتخاب کنید و **«ساخت فهرست و غربال»** را بزنید.
۶. نتیجه مثل یک جست‌وجوی معمولی نمایش داده می‌شود؛ برای هر نفر **«افزودن به فرصت»** = غربال کامل + تشخیص تکراری.

## ستون‌هایی که شناخته می‌شوند

| ستون در فایل | فارسی | کاربرد |
|---|---|---|
| First Name / Last Name | نام، نام خانوادگی | نام نمایشی |
| Name / Full Name | نام و نام خانوادگی | اگر یک ستون باشد |
| Headline / Title | عنوان، سمت | خلاصهٔ حرفه‌ای |
| Location / City | شهر، موقعیت مکانی | نمایش و غربال |
| Current Company | شرکت فعلی | سابقهٔ کاری |
| Profile URL | لینک پروفایل | شناسهٔ یکتا + دکمهٔ باز کردن پروفایل |
| Open to work | وضعیت همکاری (بله/خیر) | فیلتر «فقط آمادهٔ همکاری» |
| Skills | مهارت‌ها | غربال و نمایش |
| Education | تحصیلات | نمایش |
| Email | ایمیل | پیش‌پر کردن ایمیل دعوت مصاحبه |
| Notes / About | خلاصه، درباره | متن ورودی موتور غربالگری |

- ترتیب ستون‌ها مهم نیست؛ سرستون فارسی یا انگلیسی، با **کاما، نقطه‌ویرگول یا Tab** (اکسل فارسی معمولاً `;`).
- کدگذاری UTF-8 (با BOM هم مشکلی ندارد)؛ سلول‌های چندخطی و داخل گیومه پشتیبانی می‌شوند.
- اگر فایل **بدون سرستون** باشد، ستون اول «نام» و بقیه به‌ترتیب عنوان/شهر/شرکت فرض می‌شود و همین را هم اعلام می‌کند.
- ردیف بی‌نام کنار گذاشته می‌شود، فرد تکراری یک‌بار شمرده می‌شود، و همهٔ این‌ها در خلاصهٔ جست‌وجو نوشته می‌شود.

## «آمادهٔ همکاری» در فایل نبود چه می‌شود؟

اگر فایل ستون وضعیت را نداشته باشد، هویدا **فیلتر را اعمال نمی‌کند** و صریح می‌نویسد:
«ستون «آمادهٔ همکاری» در فایل نبود، بنابراین وضعیت همه «نامشخص» است و فیلتر اعمال نشد.»
هیچ‌وقت حدس زده نمی‌شود که کسی آمادهٔ همکاری است.

## محدودیت‌ها

- هر فایل تا **۳ مگابایت** و نتایج تا **۵۰ پروفایل** در هر بار (برای غربال بیشتر، فایل را به چند بخش تقسیم کنید).
- غربال هر پروفایل یک تحلیل هوش مصنوعی است؛ ۵۰ نفر = ۵۰ تحلیل (با موتور محلی هم کار می‌کند، فقط دقیق‌تر نیست).
- این مسیر دادهٔ جدیدی تولید نمی‌کند؛ فقط چیزی را وارد می‌کند که **شما** بیرون از هویدا دیده‌اید. مسئولیت مجوز
  استفاده از آن فهرست (قرارداد Recruiter، رضایت فرد، مدت نگهداری) با سازمان شماست.
