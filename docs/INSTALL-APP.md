# نصب هویدا روی دستگاه (اپ نصب‌شدنی)

هویدا یک **وب‌اپ نصب‌شدنی (PWA)** است: از مرورگر نصب می‌شود، آیکنش روی صفحهٔ اصلی می‌نشیند،
بدون نوار مرورگر و تمام‌صفحه باز می‌شود و وقتی اینترنت قطع شود یک صفحهٔ آفلاین فارسی نشان می‌دهد.

## چطور نصب می‌شود

| دستگاه | راه |
| --- | --- |
| اندروید (Chrome/Edge) | منوی مرورگر › «نصب برنامه» — یا گزینهٔ «نصب روی دستگاه» در منوی حساب هویدا |
| iPhone/iPad (Safari) | «اشتراک‌گذاری» › «افزودن به صفحهٔ اصلی» — یا گزینهٔ «نصب روی دستگاه» در منوی حساب که همین راهنما را نشان می‌دهد |
| دسکتاپ (Chrome/Edge) | آیکن نصب در نوار آدرس، یا همان گزینهٔ منوی حساب |

## چه چیزی واقعاً هست

- **آیکن و نام فارسی** روی صفحهٔ اصلی، با آیکن maskable برای اندروید (بریده نمی‌شود).
- **باز شدن تمام‌صفحه** (`display: standalone`) و `dir=rtl` اعلام‌شده در مانیفست.
- **میان‌برهای مانیفست**: میزکار، فرصت‌های شغلی، رزومه‌ها، اتوماسیون جذب.
- **صفحهٔ آفلاین فارسی** (`/offline.html`) که صریح می‌گوید داده‌ای روی دستگاه ذخیره نمی‌شود.
- **به‌روزرسانی بی‌دردسر:** سرویس‌ورکر با `no-cache` سرو می‌شود، نسخهٔ تازه `skipWaiting` می‌کند و
  کش قدیمی پاک می‌شود؛ پوستهٔ HTML هرگز کش نمی‌شود تا بعد از استقرار، باندل قدیمی بارگذاری نشود.

## چه چیزی عمداً نیست

- **انتشار در App Store یا Google Play.** این تصمیم جداگانه‌ای است (حساب توسعه‌دهنده، بازبینی،
  هزینهٔ سالانه). نسخهٔ وب نصب‌شدنی همین امروز کار می‌کند.
- **نوتیفیکیشن پس‌زمینه / Push.** پیاده نشده و در رابط کاربری هم وعده داده نمی‌شود.
- **دسترسی آفلاین به رزومه‌ها.** سرویس‌ورکر هیچ پاسخ `/api` را کش نمی‌کند — کش‌شدن فهرست
  کارجویان یعنی دیده‌شدن داده روی دستگاهی که ممکن است مشترک باشد. آفلاین = پوسته، نه داده.
- **کار کردن بدون سرور.** هویدا سمت سرور تصمیم می‌گیرد؛ آفلاین فقط پیام روشن می‌گیرید.

## قواعد فنی

| موضوع | رفتار |
| --- | --- |
| مانیفست | `/manifest.webmanifest` — نام، `start_url=/app`، `scope=/`، آیکن ۱۹۲/۵۱۲ PNG، maskable، میان‌برها |
| آیکن‌ها | `/brand/icon-192.png`، `icon-512.png`، `icon-maskable-512.png`، `apple-touch-icon.png` (۱۸۰×۱۸۰، iOS با SVG مشکل دارد) |
| سرویس‌ورکر | `/sw.js` با `Cache-Control: no-cache` و `Service-Worker-Allowed: /` |
| کش | فایل‌های ثابت (`/assets`, `/brand`, `/fonts`) با stale-while-revalidate؛ HTML شبکه‌اول |
| مستثنی | `/api/*`، `/scim/*`، `/admin`، صفحات عمومی کارجو، هر درخواست غیر GET |
| صفحهٔ آفلاین | `/offline.html` — فارسی، RTL، با برند و توضیح اینکه داده‌ای روی دستگاه نمی‌ماند |

## آزمون

```bash
npm run test:pwa
```

۳۳ بررسی روی سرور واقعی production: مانیفست و فیلدهایش، وجود و ابعاد واقعی هر آیکن (PNG بودن با
خواندن امضای فایل)، آیکن maskable، لینک مانیفست و apple-touch در HTML، هدرهای سرویس‌ورکر
(`no-cache` و محدودهٔ `/`)، اینکه سرویس‌ورکر `/api` و `/scim` را کش نمی‌کند، صفحهٔ آفلاین فارسی،
اینکه یک درخواست API هنوز JSON می‌دهد و هرگز صفحهٔ آفلاین نمی‌شود، و اینکه پوستهٔ `/app` سرو می‌شود.
