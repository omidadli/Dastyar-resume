# دسترسی به هر آگهی

نقش‌ها (عضو / مدیر / مالک) در کل فضای کاری کار می‌کنند. اما بعضی استخدام‌ها را نمی‌شود
به کل تیم سپرد: جانشین مدیرعامل، مدیر مالی، یا نقشی که سرپرست تیم نباید از آن باخبر شود.
هویدا برای همین حالت یک قفل **روی خود آگهی** دارد، نه روی نقش.

## چه کسی چه چیزی را می‌بیند

| نقش | آگهی «همهٔ اعضا» | آگهی «محدود» |
| --- | --- | --- |
| مالک و مدیر | می‌بیند | همیشه می‌بیند |
| سازندهٔ آگهی (حتی اگر عضو باشد) | می‌بیند | همیشه می‌بیند |
| عضوی که در فهرست است | می‌بیند | می‌بیند |
| بقیهٔ اعضا | می‌بیند | **هیچ‌جا نمی‌بیند** |

پیش‌فرض «همهٔ اعضا» است. کنترلی که کسی درخواستش نکرده و روشن باشد، فقط سوءتفاهم می‌سازد.

## کجا اعمال می‌شود

قفل فقط روی فهرست نیست؛ اگر فقط فهرست پنهان شود، بقیهٔ راه‌ها باز می‌مانند:

- **فهرست فرصت‌ها و شمارنده‌های بالای آن** — آگهی مخفی شمرده نمی‌شود.
- **صفحهٔ آگهی، تختهٔ جذب و ستون‌ها** — نشانی مستقیم هم پاسخ `403 / JOB_FORBIDDEN` می‌دهد با
  پیام روشن: «این فرصت شغلی برای شما به اشتراک گذاشته نشده است…».
- **فهرست کاندیداها و پنل کارجو** — رزومهٔ آن آگهی در هیچ فهرستی نمی‌آید؛ باز کردن مستقیم،
  یادداشت‌ها، فایل رزومه و نوشتن نظر هم رد می‌شود.
- **جابه‌جایی در تخته** — کارجوی آگهی مخفی جابه‌جا نمی‌شود.
- **پیشنهاد شغلی و لینک زمان‌بندی مصاحبه** — در فهرست دیده نمی‌شوند و باز کردنشان رد می‌شود
  (لینک عمومیِ خود کارجو مثل همیشه کار می‌کند؛ آن لینک برای خود اوست).
- **جست‌وجوی سراسری، خانه (فید فعالیت) و فهرست فعالیت‌ها** — رخدادهای آن آگهی فیلتر می‌شوند.
- **دریافت زندهٔ فایل رزومه** — با نشانهٔ امضاشدهٔ کوتاه‌عمر انجام می‌شود؛ بدون پنل، چنین نشانی‌ای
  صادر نمی‌شود.

## چگونه تنظیم می‌شود

۱. آگهی را باز کنید › منوی «کارهای بیشتر» › **دسترسی به این آگهی**
۲. سوئیچ **«محدود به افراد انتخاب‌شده»** را روشن کنید.
۳. افراد را تیک بزنید و ذخیره کنید.

- فقط **مدیر یا مالک** می‌تواند محدود/باز کند؛ عضوی که دسترسی گرفته، آن را بازنشر نمی‌کند.
- فهرست خالی پذیرفته نمی‌شود (`400 ACCESS_MEMBERS_REQUIRED`) — یا آگهی «همهٔ اعضا» است یا
  دست‌کم یک نفر انتخاب شده.
- شناسه‌های بیرون از فضای کاری نادیده گرفته می‌شوند؛ فهرست فقط از اعضای واقعی ساخته می‌شود.
- هر تغییر در فعالیت‌ها ثبت می‌شود: «دسترسی آگهی «…» را به ۲ نفر محدود کرد».
- آگهی محدود در فهرست یک نشان 🔒 «محدود» دارد و در صفحهٔ آگهی هم چیپ «دسترسی محدود» دیده می‌شود.
- برگرداندن به «همهٔ اعضا» فهرست قبلی را پاک می‌کند (نه اینکه پنهان نگه دارد).

## API

| مسیر | کار |
| --- | --- |
| `GET /api/jobs` | فقط آگهی‌های مجاز؛ شمارنده‌ها هم همان فهرست |
| `GET /api/jobs/:id` | `{ job, access }` — پیکربندی دسترسی برای ویرایشگر |
| `PUT /api/jobs/:id/access` | `{ accessMode: 'everyone' \| 'restricted', allowedUserIds: [] }` — فقط مدیر |

## آزمون

```bash
npm run test:job-access
```

۴۱ بررسی سرتاسری: پیش‌فرض باز، رد کردن فهرست خالی و شناسهٔ غریبه، فقط-مدیر بودن تغییر،
پنهان‌شدن از فهرست/شمارنده/جست‌وجو/فید، `403` روی آگهی و تخته و پنل کارجو و فایل و یادداشت و
جابه‌جایی، پنهان‌شدن پیشنهاد شغلی، حفظ دسترسی سازنده، بازکردن دوباره و ماندگاری بعد از ری‌استارت.
