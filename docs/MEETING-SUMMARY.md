# خلاصهٔ جلسه

> یک رونویسی ۲۵ دقیقه‌ای سند است، نه چیزی که کسی دوباره بخواند. کسی که فردا می‌خواهد
> تصمیم بگیرد به این نیاز دارد: چه چیز مهمی گفته شد، چه چیزی هنوز باز است، و چه قرارهایی
> گذاشته شد.

جای این قابلیت در سایت: پروندهٔ کارجو → **رونویسی گفتار** → روی هر رونویسی، دکمهٔ
**«ساخت خلاصهٔ جلسه»**.

---

## ۱. دو موتور، یک قرارداد

| موتور | چه وقت کار می‌کند | چه چیزی تولید می‌کند |
| --- | --- | --- |
| **هوش مصنوعی** | وقتی کلید AI در پنل مدیریت ثبت شده و سالم است | خلاصهٔ نوشتاری: تیتر، نکته‌های مهم، سؤال‌های باز، قدم‌های بعدی و حداکثر دو نقل‌قول |
| **موتور محلی** | همیشه — بدون هیچ کلید و هیچ سرویس بیرونی | رتبه‌بندی و دسته‌بندی **جمله‌های خودِ رونویسی**؛ هیچ جملهٔ تازه‌ای ساخته نمی‌شود |

هر دو حالت با برچسب صریح روی کارت نشان داده می‌شوند: «هوش مصنوعی · <نام مدل>» یا
«موتور محلی (بدون هوش مصنوعی)». کارت موتور محلی خودش می‌نویسد که جمله‌ها نقل شده‌اند،
نه نوشته‌شده. اگر کلید AI تنظیم نشده باشد، پاسخ API هم `note` می‌دهد که چرا محلی کار کرد.

### موتور محلی چطور کار می‌کند؟

1. متن به جمله شکسته می‌شود (نقطه، علامت سؤال فارسی «؟»، سه‌نقطه، خط جدید).
2. هر جمله با بسامد واژه‌های محتوایی‌اش (بدون واژه‌های دستوری) و وجود عدد یا تاریخ
   امتیاز می‌گیرد.
3. **اول** جمله‌های مربوط به نگرانی و سؤال باز (`نمی‌توانم`، `مشکل`، `نگرانی`، `ابهام`،
   `مطمئن نیستم`، …) و جمله‌های مربوط به قرار و قدم بعدی (`قرار است`، `تا پایان هفته`،
   `می‌فرستم`، `پیگیری`، …) برداشته می‌شوند؛ **بعد** نکته‌های مهم از باقی جمله‌ها.
   این ترتیب مهم است: یک تردید نباید فقط چون امتیاز بالایی دارد به «نکتهٔ مهم» تبدیل شود.
4. ۰ تا ۲ جملهٔ باقی‌مانده با بالاترین امتیاز به‌عنوان «از زبان خودش» نقل می‌شوند.

نتیجه: **هر خطی که می‌بینید، عیناً در رونویسی هست.** آزمون خودکار همین را اثبات می‌کند
(`npm run test:summary`): هر پنج دسته با متن اصلی مقایسه می‌شوند.

## ۲. چه چیزی در خلاصه هست و چه چیزی نیست

| هست | نیست |
| --- | --- |
| تیتر یک‌خطی | نمره یا درصد تطابق |
| ۱ تا ۵ نکتهٔ مهم | توصیهٔ «استخدام شود / نشود» |
| سؤال‌های باز و نگرانی‌ها | تحلیل شخصیت، لحن یا اعتمادبه‌نفس |
| قدم‌های بعدی و قرارها | حدس دربارهٔ چیزهایی که گفته نشده |
| حداکثر ۲ نقل‌قول | تاریخچهٔ ساختگی از جلسه |

قاعدهٔ محصول: **خلاصه تصمیم نیست.** تصمیم با نام، زمان و یادداشت در کارت ارزیابی و
تاریخچهٔ فضای کاری ثبت می‌شود.

## ۳. محدودیت‌های واقعی

- متن کوتاه‌تر از ۲۴۰ نویسه خلاصه نمی‌شود: `409 TEXT_TOO_SHORT`. خلاصهٔ دو جمله،
  دو جمله است — نه خلاصه.
- خلاصه از **متن** ساخته می‌شود، نه از صدا. اگر رونویسی خودکار تنظیم نشده باشد، اول متن
  را ثبت کنید (چسباندن متن یا فایل زیرنویس؛ جزئیات در [`TRANSCRIPTS.md`](TRANSCRIPTS.md)).
- برای رونویسی بلندتر از ۱۴٬۰۰۰ نویسه، مدل فقط همین مقدار اول را می‌خواند (سقف هزینه و
  زمان). موتور محلی روی کل متن کار می‌کند و در کارت می‌نویسد چند جمله خوانده شده است.
- ساخت دوباره مجاز است و نسخهٔ قبلی هم می‌ماند؛ فهرست همیشه جدیدترین را اول نشان می‌دهد.
  برای ساختن خلاصهٔ تازه بعد از اصلاح متن، همین دکمهٔ «ساخت دوباره» کافی است.
- اگر پاسخ هوش مصنوعی در قالب مورد نظر نباشد یا کلیدها به محدودیت بخورند، خلاصه با موتور
  محلی ساخته می‌شود و `fellBack: true` همراه با دلیل برمی‌گردد — نه خطای بی‌توضیح.

## ۴. مرزهای دسترسی و داده

| موضوع | رفتار |
| --- | --- |
| **دسترسی هر آگهی** | خلاصهٔ کارجوی یک آگهی محرمانه برای عضو بیرون از فهرست، ۴۰۳ می‌گیرد. |
| **غربالگری بی‌طرف** | تا هویت آشکار نشود، فهرست خلاصه‌ها و ساخت خلاصه با `409 BLIND_REVEAL_REQUIRED` بسته است — رونویسی هم همین‌طور. |
| **حذف رونویسی** | خلاصه‌های آن رونویسی همان لحظه پاک می‌شوند؛ خلاصه بدون متنش معنا ندارد. |
| **حذف دادهٔ کارجو (DSAR)** | خلاصه‌ها پاک می‌شوند و در شمارش «پاک‌سازی» گزارش می‌شوند. |
| **حذف فضای کاری** | همهٔ خلاصه‌ها پاک می‌شوند. |
| **جست‌وجو** | متن رونویسی در جست‌وجوی رزومه‌ها می‌آید (مثلاً «پالو آلتو» کارجو را پیدا می‌کند). |

## ۵. API

| متد و مسیر | کار |
| --- | --- |
| `POST /api/transcripts/:id/summary` | ساخت خلاصه؛ پاسخ `{ summary, fellBack, note }` |
| `GET /api/summaries?resumeId=…` | همهٔ خلاصه‌های یک کارجو (جدیدترین اول) |
| `GET /api/summaries?transcriptId=…` | خلاصه‌های یک رونویسی |
| `DELETE /api/summaries/:id` | پاک‌کردن یک خلاصه |

کدهای خطا: `TEXT_TOO_SHORT`، `TRANSCRIPT_NOT_FOUND`، `BLIND_REVEAL_REQUIRED`.

## ۶. آزمون

```bash
npm run test:summary      # ۳۷ بررسی
```

پوشش: برچسب و متن دلیل موتور محلی، **عدم اختراع** (همهٔ خطوط زیررشتهٔ رونویسی‌اند)،
شناسایی تردید و قرار، تیتر و شمارش جمله، فهرست به تفکیک کارجو/رونویسی، نسخهٔ تازه و
ترتیب، جداسازی فضاهای کاری، بسته‌شدن در حالت بی‌طرف (هم خلاصه و هم رونویسی)، حذف
زنجیره‌ای رونویسی → خلاصه، پاک‌سازی DSAR با شمارش، و جست‌وجوی متن رونویسی.
