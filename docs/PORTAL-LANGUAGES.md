# پورتال دوزبانه (فارسی / انگلیسی)

پورتال شغلی تنها صفحه‌ای است که بسیاری از کارجوها از سازمان می‌بینند. برای بخشی از
کارجوها — مهاجران، نیروهای بین‌المللی، یا کسانی که انگلیسی را راحت‌تر می‌خوانند — یک صفحهٔ
تمام‌فارسی دیوار است. هویدا پورتال را دوزبانه می‌کند، بدون اینکه حرف کارفرما را عوض کند.

## روشن‌کردن

تنظیمات › ابزارها و اتصال‌ها › **پورتال شغلی**:

| گزینه | کار |
| --- | --- |
| نسخهٔ انگلیسی پورتال | دکمهٔ زبان روی صفحهٔ عمومی + `hreflang` برای گوگل |
| زبانی که بازدیدکننده اول می‌بیند | فارسی یا English |

فارسی همیشه روشن است؛ «انگلیسی» یک سوئیچ است. اگر زبان پیش‌فرض انگلیسی باشد ولی انگلیسی
خاموش، سرور بی‌سروصدا به فارسی برمی‌گردد (صفحه‌ای که وجود ندارد ساخته نمی‌شود).

## چرا متن آگهی ترجمهٔ خودکار نمی‌شود

هر سیستم استخدامی می‌تواند متن شما را ماشینی ترجمه کند؛ اما آگهی شغلی **حرف کارفرما**ست:
شرط‌ها، لحن و تعهدها. هویدا این تصمیم را به منابع انسانی می‌سپارد:

- در «ویرایش اطلاعات فرصت شغلی» بخش **نسخهٔ انگلیسی** دو فیلد هست: عنوان انگلیسی و شرح انگلیسی.
- اگر پر باشند، پورتال انگلیسی همان را نشان می‌دهد و `JobPosting` هم با `inLanguage: en`
  همان عنوان را به گوگل می‌دهد.
- اگر خالی باشند، پورتال انگلیسی **متن اصلی** را نشان می‌دهد و بالای آن یک یادداشت صادقانه:
  «این آگهی به فارسی نوشته شده است؛ متن اصلی کارفرما را می‌بینید.»
- خالی‌کردن فیلدها نسخهٔ انگلیسی را برمی‌دارد؛ هیچ ترجمهٔ ماشینی جایی ذخیره نمی‌شود.

## سمت مرورگر

- `?lang=en` یا `?lang=fa` زبان را تعیین می‌کند؛ بدون پارامتر، زبان پیش‌فرض سازمان.
- دکمهٔ زبان در هدر، پارامتر را عوض می‌کند و مسیر (و کد معرف) را حفظ می‌کند.
- جهت صفحه و `lang` سند هم با زبان عوض می‌شود (`rtl`/`ltr`).
- اعداد با ارقام همان زبان نوشته می‌شوند (۳ فرصت / 3 roles).
- برچسب‌های نوع همکاری هم ترجمه شده‌اند (تمام‌وقت / Full-time).
- پرسش‌های پرسش‌نامه و عنوان شغل، همان متنی است که کارفرما نوشته.

## سمت گوگل

- `hreflang="fa"` و `hreflang="en"` و `x-default` روی هر صفحه (وقتی انگلیسی روشن است)،
  تا دو زبان «محتوای تکراری» شمرده نشوند.
- `JobPosting.inLanguage` زبان واقعی متن را می‌گوید (`fa` یا `en`).
- آگهی منقضی همچنان `noindex` است؛ دوزبانه بودن این قاعده را تغییر نمی‌دهد.

## API

| مسیر | کار |
| --- | --- |
| `GET /api/careers/:slug` | `portal: { languages, defaultLang }` + آگهی‌ها با `titleEn` |
| `GET /api/careers/:slug/jobs/:id` | `descriptionEn` هم اضافه می‌شود |
| `GET/PUT /api/careers/settings` | `languages: ['fa','en']`، `defaultLang` — نوشتن فقط مدیر |
| `PATCH /api/jobs/:id` | `titleEn`، `descriptionEn` (رشتهٔ خالی = برداشتن نسخهٔ انگلیسی) |

## آزمون

```bash
npm run test:portal-langs
```

۲۷ بررسی: پیش‌فرض فارسی، فقط-مدیر بودن تغییر زبان، روشن/خاموش کردن انگلیسی، بازگشت امن زبان
پیش‌فرض، نسخهٔ انگلیسی آگهی در پورتال و در `JobPosting`، `hreflang`، نبودِ ترجمهٔ ساختگی برای
آگهی فارسی، برداشتن نسخهٔ انگلیسی و ماندگاری بعد از ری‌استارت.
