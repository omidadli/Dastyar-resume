# رونویسی گفتار

سابقهٔ استخدام با گفت‌وگو ساخته می‌شود، و بیشتر گفت‌وگوها هیچ‌جا نوشته نمی‌شوند. «رونویسی گفتار»
همان تماس تلفنی، یادداشت صوتی یا پاسخ ویدئویی را به متنی تبدیل می‌کند که همکارتان فردا می‌تواند
بخواند، نقل کند و جست‌وجو کند.

## سه راه — از همیشه‌کار‌کننده تا خودکار

| راه | چه وقت کار می‌کند | برچسب |
| --- | --- | --- |
| **چسباندن متن** | همیشه؛ بدون هیچ کلید و سرویسی | «دستی» |
| **فایل زیرنویس** (`.srt` / `.vtt` / `.txt`) | همیشه؛ زمان‌ها روی همین سرور خوانده می‌شوند | «پردازش محلی» |
| **فایل صوتی/تصویری** | وقتی کلیدی از نوع Gemini (که صدا می‌خواند) در پنل مدیریت ثبت شده باشد | نام همان سرویس |

صفحهٔ «رونویسی گفتار» **قبل از** بارگذاری می‌گوید کدام راه باز است. اگر رونویسی خودکار تنظیم نشده
باشد، فایل ذخیره می‌شود و ردیف با وضعیت «متن لازم است» می‌ماند — هویدا هرگز متن ساختگی نمی‌سازد.

## مسیر استفاده

- **پروفایل کارجو › رونویسی گفتار** — سه تب: چسباندن متن، فایل زیرنویس، فایل صوتی/تصویری.
  هر رونویسی با عنوان، منبع، تاریخ و نام سرویس/«دستی» در فهرست می‌ماند؛ متن قابل کپی و حذف است و
  فایل اصلی با پخش‌کنندهٔ کوچک شنیده می‌شود.
- **مصاحبهٔ ویدئویی › تماشا و امتیاز** — زیر هر پاسخ دکمهٔ «رونویسی این پاسخ»؛ متن کنار همان
  ویدئو می‌نشیند و به همان دعوت وصل می‌شود.

## قواعد فنی

| موضوع | رفتار |
| --- | --- |
| فرمت‌های پذیرفته‌شده | mp3، m4a، wav، ogg، opus، flac، aac، webm، mp4، mov |
| سقف حجم | ۴۰ مگابایت برای هر فایل |
| زیرنویس | SRT (میلی‌ثانیه با کاما) و WebVTT (با نقطه، تگ‌های `<c>`/`<i>` پاک‌شده) |
| زمان‌ها | میلی‌ثانیه ذخیره و در رابط کاربری «۰۱:۲۰ تا ۰۱:۲۴» نمایش داده می‌شوند |
| پخش فایل اصلی | لینک امضاشدهٔ ۳۰ دقیقه‌ای با پشتیبانی `Range` |
| جست‌وجو | متن رونویسی‌ها در جست‌وجوی رزومه‌ها شرکت می‌کند — جمله‌ای که در تماس شنیده‌اید کارجو را پیدا می‌کند |
| غربالگری بی‌طرف | در حالت بی‌طرف، رونویسی‌ها هم پنهان‌اند (`BLIND_REVEAL_REQUIRED`) چون نام و جزئیات هویت را لو می‌دهند |
| دسترسی هر آگهی | رونویسی کارجوی یک آگهی محرمانه برای عضو بی‌دسترسی `403` است |
| درخواست حذف داده | با «پاک‌سازی کامل کارجو» متن و فایل صوتی هم حذف می‌شوند (شمارش در پاسخ API) |
| ثبت رویداد | هر افزودن/ویرایش/پاک‌کردن در فعالیت‌های تیم ثبت می‌شود |

## چرا کلید Gemini؟

کلیدهای OpenAI-compatible فعلی هویدا فقط متن، PDF و تصویر می‌خوانند؛ صدا را نمی‌خوانند. به‌جای
وعدهٔ الکی، صفحه همین را می‌گوید و دو راه دیگر را پیشنهاد می‌کند. برای فعال‌کردن رونویسی خودکار:
**پنل مدیریت › کلیدهای هوش مصنوعی** › یک کلید Gemini اضافه کنید (یا `GEMINI_API_KEY` را در محیط
سرور بگذارید) و «ذخیره» بزنید. بعد از آن، مسیر صوتی بدون تغییر دیگری کار می‌کند.

## آزمون

```bash
npm run test:transcript
```

چهل‌وهشت بررسی سرتاسری: صداقت وضعیت بدون کلید، رد متن کوتاه، متن دستی، پارس SRT و VTT (زمان‌ها،
کاما/نقطه، پاک‌سازی تگ‌ها)، متن ساده بدون زمان ساختگی، فایل صوتی در حالت بدون کلید (ذخیره + پیام
دلیل)، پخش امضاشده با `Range` و رد امضای دست‌کاری‌شده، رد PDF، تکمیل متن دستی و برچسب
«دستی (بازبینی‌شده)»، رونویسی پاسخ ویدئویی و پیوندش به همان دعوت، جست‌وجو در متن رونویسی،
پنهان‌شدن در حالت بی‌طرف، جداسازی فضاهای کاری، حذف فایل با حذف رونویسی، پاک‌سازی DSAR و
ماندگاری بعد از ری‌استارت.
